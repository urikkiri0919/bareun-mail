# 바른메일 크롬 확장프로그램 MVP 설계 초안

상태: 설계 검토용 초안
작성일: 2026-10-22

## 의도와 배경

업무 메일을 자주 쓰는 사람은 맞춤법, 정중한 비즈니스 문맥, 중복 표현과 문장 흐름을 확인하려고 초안을 다른 AI 도구에 다시 붙여넣곤 한다. 바른메일은 크롬에서 바로 열어 초안을 넣고, 나중에 AI 보정 API를 연결해 다듬은 메일만 받는 확장프로그램이다.

이번 저장소 준비 단계에서는 실제 AI 보정을 구현하지 않는다. API가 아직 준비되지 않았으므로 확장프로그램의 최소 UI와 재사용 가능한 보정 규칙 문서를 준비한다. 보정되지 않은 내용을 실제 결과처럼 보이게 하지는 않는다.

## 대상 사용자

업무 메일을 자주 작성하고, 보내기 전 맞춤법과 문맥을 다시 확인하는 사람. 특정 직무나 메일 서비스에 한정하지 않는다.

## 목표

- Windows의 Chrome에서 Manifest V3 확장프로그램으로 로드할 수 있다.
- 도구 모음 또는 `Ctrl+Shift+E` 단축키로 팝업을 연다. 단축키는 Chrome의 확장프로그램 단축키 설정에서 사용자가 바꿀 수 있다.
- 초안 입력 영역과 보정 결과 영역을 가진 작은 화면을 제공한다.
- API 미연결 상태임을 분명히 알리고, 보정 버튼은 비활성화하거나 연결 준비 안내를 보여준다. 가짜 보정 결과를 만들지 않는다.
- `docs/correction-rules.md`에 향후 AI에 적용할 보정 기준을 기록한다.

## 보정 규칙

1. 원문의 의미와 사실을 보존한다. 이름, 회사명, 제품명·모델명, 수량, 금액, 날짜, 약속을 임의로 바꾸지 않는다.
2. 맞춤법과 띄어쓰기를 바로잡는다.
3. 정중하고 자연스러운 비즈니스 문맥으로 다듬되, 필요 이상으로 길게 만들지 않는다.
4. 중복 표현을 줄이고 문장 순서와 흐름을 자연스럽게 정리한다.
5. 모호한 내용을 추측해 채우지 않는다. 확실하지 않은 부분은 원문의 사실을 유지해 사람이 검토하게 한다.
6. API 연결 후 결과는 수정 이유나 분석 설명 없이 보정된 메일 텍스트만 반환한다.

## 첫 단계의 구성과 범위

- Chrome Manifest V3 확장프로그램.
- 작은 팝업 UI: 초안 입력, 결과 표시 영역, API 미연결 안내.
- 기본 단축키 `Ctrl+Shift+E`; 사용자 재지정 가능.
- 보정 규칙을 별도 Markdown 문서로 관리해 API 연결 시 재사용.
- 첫 단계에서는 초안을 저장하거나 외부로 전송하지 않는다.

### 하지 않을 것

- AI API 호출 및 실제 자동 보정.
- API 키를 확장프로그램 코드에 넣거나 저장소에 커밋.
- 특정 메일 서비스 화면에 직접 삽입·연동.
- 메일 자동 발송, 수신함 접근, 고객정보 저장.
- 설명문·수정 이유 출력, 첨부파일 처리, 여러 메일 일괄 처리.

## 에이전트와 사용자 역할

- Hermes: 확장프로그램 기본 화면과 매니페스트를 준비하고, 보정 규칙 문서를 작성하며, 로컬 로드·단축키 동작을 확인한다.
- 황길종: 보정 규칙과 화면 문구를 검토하고, 실제 사용자에게 필요한 기준인지 판단한다. API가 추가되면 개인정보 처리와 결과의 사실 정확성을 결정·확인한다.
- 최종 메일 내용과 발송 여부는 항상 사용자가 판단한다.

## 기술과 제약

- Manifest V3, HTML/CSS/JavaScript만 사용하고 외부 라이브러리는 추가하지 않는다.
- API 공급자와 인증·서버 구조는 아직 정하지 않는다. API 연결 작업이 시작될 때 별도 설계한다.
- 첫 단계의 로컬 검증은 Chrome의 `chrome://extensions`에서 개발자 모드로 압축해제된 확장프로그램을 불러오는 방식이다.
- API 연결 전에는 메일 본문이 네트워크로 나가지 않아야 한다.

## 검증 계획

1. `manifest.json`이 유효한 JSON이며 Manifest V3 형식인지 확인한다.
2. Chrome에서 확장프로그램을 로드하고 도구 모음 및 `Ctrl+Shift+E`로 팝업이 열리는지 확인한다.
3. 팝업의 입력·결과 영역과 API 미연결 안내가 보이고, 보정 결과를 가장하지 않는지 확인한다.
4. Chrome 단축키 설정에서 기본 조합을 다른 조합으로 바꿀 수 있는지 확인한다.
5. API 미연결 상태에서 입력 본문이 저장되거나 네트워크 요청으로 전송되지 않는지 확인한다.
6. 보정 규칙 문서가 사실 보존, 맞춤법, 정중한 문맥, 중복 제거, 출력 형식 요구를 모두 포함하는지 검토한다.

## 위험과 가정

- API 연결 후에는 메일 본문이 외부 서비스로 전송될 수 있다. 실제 연결 전에 데이터 처리·보안·비용을 별도로 결정한다.
- 확장프로그램에 API 키를 직접 넣으면 노출될 수 있으므로, 키 보관 방식과 호출 구조는 별도 설계 없이 구현하지 않는다.
- `Ctrl+Shift+E`는 기본 제안일 뿐, Chrome·운영체제·다른 확장프로그램과 충돌할 수 있으므로 사용자가 설정에서 변경할 수 있어야 한다.
- 첫 단계는 동작하는 문장 보정기가 아니라, API 연결 전의 확장프로그램 UI와 규칙을 준비하는 단계다.
