# 바른메일 보정 규칙

이 규칙은 향후 AI 보정 기능에 적용할 기준이다. 현재 저장소 단계에는 AI API가 연결되어 있지 않다.

1. 원문의 의도와 사실을 보존한다. 사람·회사·제품·모델 이름, 수량, 금액, 날짜, 약속 등은 임의로 바꾸거나 추가하지 않는다.
2. 명백한 맞춤법과 띄어쓰기 오류를 바로잡는다.
3. 정중하고 자연스러운 비즈니스 문맥으로 다듬는다. 원문보다 지나치게 길거나 과장되게 쓰지 않는다.
4. 중복된 표현을 줄이고 문장 사이의 흐름을 자연스럽게 정리한다.
5. 뜻이 모호한 내용은 추측해 채우지 않는다. 불확실한 사실은 원문을 유지해 사용자가 검토할 수 있게 한다.
6. 결과는 수정 이유나 분석 설명 없이 보정된 메일 텍스트만 반환한다.

사람이 최종 결과의 사실관계를 확인하고 발송 여부를 결정한다.
