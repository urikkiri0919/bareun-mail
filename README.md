# 바른메일

업무 메일 초안의 맞춤법과 비즈니스 문맥을 다듬기 위한 Chrome 확장프로그램 MVP입니다.

## 현재 단계

- Manifest V3 기반 확장프로그램의 기본 구조를 준비 중입니다.
- AI API는 아직 연결하지 않았습니다. 이 단계에서는 초안이 자동 보정되지 않습니다.
- 향후 보정 기준은 [`docs/correction-rules.md`](docs/correction-rules.md)에 정리합니다.

## 로컬에서 불러오기

팝업 파일이 준비된 뒤 Windows Chrome에서 다음 순서로 실행합니다.

1. 주소창에 `chrome://extensions`를 입력합니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 선택하고 이 저장소 폴더를 지정합니다.
4. 도구 모음의 바른메일 아이콘을 눌러 팝업을 엽니다.

## 단축키

기본 제안은 `Ctrl+Shift+E`입니다. 조합이 충돌하면 `chrome://extensions/shortcuts`에서 변경할 수 있습니다.

## 개인정보와 보안

- API가 연결되기 전에는 입력한 메일 내용을 네트워크로 보내거나 저장하지 않습니다.
- 현재 단계에는 메일 서비스 접근 권한이 없습니다.
- API 키나 고객의 실제 메일 내용은 소스 코드나 이 저장소에 넣지 않습니다.
- API를 연결하기 전에는 전송 대상, 키 보관 방식, 비용과 개인정보 처리를 별도로 결정해야 합니다.
